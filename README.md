# LUMEN V2

LUMEN is a self-hosted, privacy-first metasearch application built with Next.js and an independent Python/FastAPI search backend. It queries documented external sources concurrently, normalizes and deduplicates results, and applies deterministic, explainable ranking. It does not crawl or index the entire web.

Keyless sources cover Wikipedia, Wikimedia Commons images, GitHub repositories, Crossref scholarly metadata and Hacker News discussions. An optional official Brave API integration adds general-web results. No paid key, SearXNG service, database or cloud account is required for the basic stack. Availability depends on upstream services and their quotas.

The frontend provides supported categories, URL-based filters, engine selections, local search profiles, ranking explanations, side-by-side comparison and IndexedDB research collections with notes, tags, JSON/Markdown export and validated import. Settings include appearance and optional local history. Collections stay in the browser.

## Run with Docker

```sh
git clone https://github.com/namelessweakl1ng/LUMEN.git
cd LUMEN
cp .env.example .env
docker compose up --build -d
```

Open http://localhost:3000. Check `docker compose ps` and `curl --fail http://localhost:3000/api/v1/health`. Only the frontend port is published; the backend stays on the internal network. See [deployment](docs/deployment.md) for local uv/Bun development, Fedora guidance, optional source keys, HTTPS and troubleshooting.

## Architecture

```text
Browser: Next.js / React / TypeScript / Tailwind / Zustand / IndexedDB
   -> same-origin Next.js API forwarding
   -> FastAPI / Pydantic / HTTPX / asyncio
   -> adapter registry -> concurrent documented source APIs
   -> canonicalization -> filtering -> deduplication -> ranking -> TTL cache
```

Python 3.12+, uv, Node 22 and Bun are used for development. Containers use non-root runtime users, health checks, multi-stage builds and frozen dependency locks. Search API schemas are generated by FastAPI at `/docs` on the backend.

## Limitations

Keyless sources offer domain-specific discovery rather than comprehensive web coverage. Hacker News is technology-oriented; Crossref supplies metadata rather than guaranteed full text. Optional Brave requires a server-side key. Maps and videos remain unavailable without a real permitted integration. Provider-specific filters and pagination vary; local post-filters may reduce returned counts. Rankings and overlap are explainable heuristics, not objective quality scores.

Caches, throttling state and diagnostics are process-local; adding workers multiplies provider traffic. Browser storage belongs to its origin, so export collections before moving hosts. Upstream queries and directly loaded images have privacy implications described in the privacy guide.

V1 used SearXNG. V2 independently implements its search layer while preserving Git history and the existing [license](LICENSE).
